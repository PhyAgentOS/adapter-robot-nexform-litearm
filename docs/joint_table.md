# LiteArm 关节参数表（权威来源待确认）

本表由 `assets/urdf/litearm.urdf` 与 `assets/mjcf/litearm7.xml` 直接解析得到。
其余参数（SDK/固件/夹爪/VR）见 [`parameters.md`](parameters.md)。
MJCF 自 2026-11-05 起按 URDF 重建（`litearm-mujoco` `b901d49`），轴方向与限位
逐项一致；固件侧零位/正方向仍需真机确认。

## 1. 基本信息

| 项 | 值 | 来源 |
|---|---|---|
| 关节数 | 7（旋转） | URDF / MJCF |
| 关节名 | `joint1` … `joint7` | 两者一致 |
| 顺序 | 1 → 7 | 两者一致 |
| 单位 | rad | URDF / MJCF `angle="radian"` |
| 末端 | `ee_link`（fixed） + MJCF `tcp` site | URDF / MJCF |
| 夹爪 | LiteGrip，两指总开口 0–0.080 m | LiteGrip 出厂标定 |

## 2. URDF 与 MJCF 对照

| 关节 | URDF 轴 | URDF 限位 (rad) | MJCF 轴 | MJCF 限位 (rad) | 一致性 |
|---|---|---|---|---|---|
| joint1 | 0 0 1 | -2.827 .. 2.827 | 0 0 1 | -2.827 .. 2.827 | 一致 |
| joint2 | 0 0 1 | -1.745 .. 1.745 | 0 0 1 | -1.745 .. 1.745 | 一致 |
| joint3 | 0 0 1 | -2.827 .. 2.827 | 0 0 1 | -2.827 .. 2.827 | 一致 |
| joint4 | 0 0 1 | -3.089 .. 0.035 | 0 0 1 | -3.089 .. 0.035 | 一致 |
| joint5 | 0 0 1 | -2.827 .. 2.827 | 0 0 1 | -2.827 .. 2.827 | 一致 |
| joint6 | 0 0 -1 | -1.571 .. 1.571 | 0 0 -1 | -1.571 .. 1.571 | 一致 |
| joint7 | 0 0 1 | -1.571 .. 1.571 | 0 0 1 | -1.571 .. 1.571 | 一致 |

结论：MJCF 与 URDF 的关节坐标、轴、限位逐项一致，`q` 可直接共用，不再需要符号换算。
旧版 MJCF（另一款臂，joint2/joint6 轴相反、joint4 上限 0.647）已移除。

## 3. 零位与正方向

| 项 | 现状 |
|---|---|
| 零位定义 | URDF/MJCF 均为全 0；SDK `home()`（0x2A）回 `[0]*7`；实测对照**待确认** |
| 正方向 | URDF 右手定则绕轴；固件正方向：**待上位机方向检测确认** |
| 固件软限位 | 通过 `arm.get_state()` / 参数读取确认，**未归档** |

## 4. 单位与量纲

| 量 | 单位 | 说明 |
|---|---|---|
| 关节位置 | rad | SDK `JointState.q` 已是 rad |
| 关节速度 | rad/s | `dq` |
| 关节力矩 | Nm | `tau` |
| 夹爪开口 | m | SDK 是 mm，`codec.mm_to_m` 换算 |
| TCP 位姿 | m + rad | `get_tcp().value` 为法兰位姿 |
