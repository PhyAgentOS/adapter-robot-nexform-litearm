# LiteArm Modified DH 参数表

厂商未提供 MDH。本表由本仓 `assets/urdf/litearm.urdf` 反推得到，
用于满足接入标准 §10/§12 的参数记录要求；当前运行时代码（VR / IK）仍然
走 URDF，不消费本表。

- 生成脚本：`scripts/urdf_to_mdh.py`
- 复现 / 对拍：`python scripts/urdf_to_mdh.py --check 500`
- 结果：500 组随机 `q` 与 URDF FK 对比，位置最大误差 `1.9e-11 m`，
  旋转矩阵最大元素误差 `5.4e-11`。

## 1. 约定

采用 Craig 的 Modified DH：

```text
^{i-1}T_i = Rx(alpha_{i-1}) * Tx(a_{i-1}) * Rz(theta_i + theta0_i) * Tz(d_i)
theta_i = q_i + theta0_i
```

- `q_i` 是 URDF 关节角（rad），**正方向与 URDF `<axis>` 一致**，
  直接以加号叠加到 `theta0_i`。
- frame i（i = 1…7）的 z 轴取 joint i 的转轴；frame 0 的 z 轴取 joint1 转轴，
  原点放在 `base_link` 原点。
- `x_i`（i = 1…6）取 `z_i` 到 `z_{i+1}` 的公垂线；frame 7 的 x 取 `ee_link`
  x 轴在垂直于 `z_7` 平面上的投影。
- 完整链：`T_base_ee(q) = T_0 * Π A_i(q_i) * T_7_ee`，其中 `T_0` 和 `T_7_ee`
  见 §3。

## 4. 校验与复现

```bash
python scripts/urdf_to_mdh.py --check 500 --digits 6
```

脚本会：

1. 解析 URDF 串链，求 `q=0` 时各关节转轴的世界位姿；
2. 用相邻转轴公垂线构造 DH 坐标系，分解出 `alpha / a / theta0 / d`；
3. 用 500 组随机 `q` 对 URDF FK 和本表 FK 做对拍。

全精度参数的对拍误差见文首。把表中数值舍入到 6 位小数后再对拍，
位置误差约 `1.4e-6 m`、旋转矩阵元素误差约 `1.9e-6`，不影响使用。

## 5. 说明与限制

- URDF 的 `rpy` 只保留到 1e-4 rad（写的是 `1.5708` 而不是 `pi/2`），
  因此 `alpha` 与 `pi/2`、`theta0` 与 `±pi/2` / `±pi` 之间存在
  `1e-6 ~ 1e-5` 量级的偏差。这是输入精度造成的，不是推导误差。
- 相邻关节轴不能平行；本臂 7 个关节轴两两不平行，满足反推条件。
  脚本遇到平行轴会直接报错。
- 若厂商后续提供官方 MDH，应以官方表为准，并与本表做 FK 对拍后替换。
- 本表目前只用于验收记录；驱动 / VR / IK 代码不读取本表。
